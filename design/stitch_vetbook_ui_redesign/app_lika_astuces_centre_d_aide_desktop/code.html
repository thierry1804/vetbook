Transition alimentaire progressive

Changement sur 7 à 10 jours

Le microbiote gastro-intestinal canin s'adapte lentement. Intégrez : J1-J3 (75% ancien / 25% nouveau), J4-J6 (50/50), J7-J9 (25/75), puis 100% au dixième jour pour éviter les diarrhées aiguës.

Surveillance des ergots
