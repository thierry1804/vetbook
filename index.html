Questions fréquentes

Comment activer la sauvegarde dans le cloud ?
Dans « Mon compte », connecte-toi avec Google ou reçois un lien de connexion par email. Une fois connecté, utilise « Sauvegarder dans le cloud » pour envoyer tes données, ou « Restaurer depuis le cloud » pour les récupérer sur un autre appareil.
Mes données sont-elles conservées si je ne me connecte pas ?
Oui. Sans connexion, l'application reste 100 % locale : tout est stocké sur cet appareil, rien n'est envoyé ailleurs.
Comment ajouter un rappel de vaccin ou de déparasitage ?
Dans la fiche de l'animal, onglet « Vaccins » ou « Déparasitage », bouton « + ». Renseigne la date du prochain rappel pour qu'il apparaisse dans les Alertes et le Calendrier.
Comment recevoir des notifications de rappel ?
Dans « Mon compte » → « Notifications », active les notifications du navigateur. Un compte cloud connecté est nécessaire pour les recevoir même app fermée.
Comment exporter mes données ?
Dans « Mon compte » → « Sauvegarde / Import », télécharge une sauvegarde complète au format JSON. Depuis l'onglet « Alertes » d'un animal, tu peux aussi exporter les rappels à venir au format calendrier (.ics).
J'ai supprimé un animal par erreur, puis-je le récupérer ?
Non, la suppression d'un animal est définitive. Pense à exporter une sauvegarde régulièrement (« Mon compte » → « Sauvegarde / Import ») pour pouvoir restaurer en cas d'erreur.
